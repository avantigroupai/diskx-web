# DiskX — website

Landing page for **DiskX**, the free, open-source macOS disk space analyzer and
disk explorer.

- **Live site:** https://avantigroupai.github.io/diskx-web/
- **App source:** https://github.com/avantigroupai/DiskX
- **Download:** https://github.com/avantigroupai/DiskX/releases/latest

Single self-contained `index.html` — no build step, no dependencies — plus a
`/contact/` redirect page, `llms.txt`, `robots.txt` and `sitemap.xml` for search
and answer-engine discoverability. Served via GitHub Pages.

Analytics: Cloudflare Web Analytics (cookieless) and Google Analytics.

Built with a multi-agent AI orchestration pipeline · avantigroup.ai
